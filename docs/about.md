# KIKSについて
KIKSは、ロボカップサッカー小型リーグ（SSL）に参加しているチームです。豊田高専の学生を中心に活動しています。

# ロボカップSSLについて
> 直径18cm、高さ15cmのロボットでサッカーをする競技です。
> ロボカップ随一のスピーディーなゲーム展開が魅力です。
> 戦略も非常に高度で、人間を凌ぐ連携プレーが見られます。
([RoboCup SSL Japan ホームページ](https://www.ssl.robocup.or.jp/about/))

# 超小型サッカーロボットについて
SSLで用いられる高価なサッカーロボットに代わり、低コストで製作可能な超小型サッカーロボットでロボットサッカーゲームをしようという試みです。


**SSL**(Small Size League)に代わり、**VSSL**(Very Small Size League)と呼んでいます。
