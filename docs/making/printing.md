stlファイルは
[グーグルドライブ](https://drive.google.com/drive/folders/1fOG-YyxghJurZSG6twQviDu5QsxXvmG_?usp=drive_link)
の**stl_easyフォルダ**にあります。

**stlフォルダ**は旧バージョンなので注意。

| 部品種類 | ファイル名 | 必要数 |
| ---- | ---- | ---- | 
| モーター固定用パーツ | te_base_lid.stl | 1 |
| ベースプレート | te_base.stl | 1 |
| 電池ボックスホルダー | te_battery_case.stl | 1 |
| カバーフタ | te_cover_lid.stl | 1 |
| カバー | te_cover.stl | 1 |
| ギア | te_gear.stl | 1 |
| キックバー | te_kicker.stl | 1 |
| 2段目モーター固定用パーツ | te_middle_lid.stl | 1 |
| 2段目 | te_middle.stl | 1 |
| オムニホイール部品（内側）| te_omni_inside.stl | 1 |
| オムニホイール部品（外側）| te_omni_outside.stl | 1 |
| オムニホイール用タイヤ | te_omni_tire.stl | 36 |

- ギヤ、ホイール、タイヤは、精度を高めの設定にして印刷すること。
- 印刷するときの部品の向きは、平らな面を下にすること。
- キックバー以外のパーツはPLAフィラメント
- キックバーは、PETGフィラメントを使うとよい（PLAより柔軟性が高いので）
